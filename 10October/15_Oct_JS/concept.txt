JS file  -> Code -> Run -> Browser -> Console.window 

JS FIle code is embedded into html and html is rendered on Browser which use Javascript Engine to run Javascript.
Each browser has their specific JS Engine
Eg Chrome -> V8 Engine 
   Edge -> Chakra
   Firefox -> SpiderMonkey


JS Engine -> Parser -> Abstract Syntax Tree
               |
            JIT Compiler -> Interpreter -> Processor 

EXPLAINATION
============by Sir 
-The Javascript code is received by Javascript Engine which is present in browser.
-Firstly javascript code is received by parser which separates the code into smaller chunks such as functions, variables, operators.
-Now the code is sent to Abstract syntax tree. A deeply tree structure which represents grammatical logic of program and also keeps the track of every type of code.
- Now the code received by Just In Time Compiler(JIT) which converts source code into byte code and check the high level syntax.
- The code which be sent to the Interpreter which executes code line by line. Next the code will be tranferred to Processor which converts bytecode into high level language
