CSS Attribute Selectors
CSS attribute selectors let you select HTML elements based on the presence or value of an attribute.

They are useful when you want to style elements without adding extra classes or IDs.

For example:

<input type="text">
<input type="email">
<input type="password">

Instead of adding classes to every input, you can select them using their type attribute:

input[type="email"] {
  border: 2px solid blue;
}
This styles only the <input> whose type is "email".

1. Basic Attribute Selector [attribute]
The simplest form checks whether an attribute exists.

Syntax
[attribute] {
  property: value;
}
Example
<input type="text" required>
<input type="email">
<input type="password" required>
[required] {
  border: 2px solid red;
}
Result
Both of these elements are selected:

<input type="text" required>
<input type="password" required>
Because they have the required attribute.

The email input is not selected because it doesn't have required.

2. Attribute Equals [attribute="value"]
This selects elements where an attribute has an exact value.

Syntax
[attribute="value"] {
  property: value;
}
Example
<input type="text">
<input type="email">
<input type="password">
input[type="email"] {
  background-color: lightblue;
}
Only this element is selected:

<input type="email">

<a href="about.html">About</a>
<a href="contact.html">Contact</a>
a[href="about.html"] {
  color: red;

The ^= operator means:

The attribute value starts with this text.

Syntax
[attribute^="value"] {
  property: value;
}

Example
<a href="https://google.com">Google</a>
<a href="https://youtube.com">YouTube</a>
<a href="about.html">About</a>

a[href^="https"] {
  color: green;
}

This selects:

<a href="https://google.com">
<a href="https://youtube.com">

because both values start with:

https

But this isn't selected:

<a href="about.html">

because it doesn't start with https.

Practical use
You can use it to identify external links:

a[href^="https://"] {
  color: green;
}

The $= operator means:

The attribute value ends with this text.

Syntax
[attribute$="value"] {
  property: value;
}

<a href="document.pdf">PDF</a>
<a href="image.jpg">Image</a>
<a href="notes.pdf">Notes</a>

a[href$=".pdf"] {
  color: red;

<a href="document.pdf">
<a href="notes.pdf">

because both end with:

.pdf

Different styles for different file types:

a[href$=".pdf"] {
  color: red;
}

a[href$=".jpg"] {
  color: blue;
}

a[href$=".zip"] {
  color: purple;
}

The *= operator means:

The attribute value contains this text anywhere.

Syntax
[attribute*="value"] {
  property: value;
}

<a href="https://google.com">Google</a>
<a href="https://facebook.com">Facebook</a>
<a href="https://example.com/google-page">Page</a>

a[href*="google"] {
  color: red;
}

This selects:

<a href="https://google.com">
<a href="https://example.com/google-page">

because "google" appears somewhere in the href.

The ~= operator checks for a complete word in a space-separated attribute value.

Syntax
[attribute~="word"] {
  property: value;
}

This is particularly useful with attributes such as class.

Consider:

<div class="box red large">Box 1</div>
<div class="box blue small">Box 2</div>
<div class="box red">Box 3</div>

You can write:

[class~="red"] {
  color: red;
}

This selects:

<div class="box red large">
<div class="box red">

But it would not match something like:

<div class="box reddish">

because red is not a separate word there.

Difference between *= and ~=
[class*="red"]

means:

Does the attribute contain "red" anywhere?

While:

[class~="red"]

means:

Does the attribute contain "red" as a separate space-separated word?

The |= operator is less commonly used.

It selects an attribute whose value is either:

exactly the specified value, or

starts with that value followed by -.

Example
<div lang="en">English</div>
<div lang="en-US">American English</div>
<div lang="en-GB">British English</div>
<div lang="fr">French</div>

CSS:

[lang|="en"] {
  color: blue;
}

This selects:

<div lang="en">
<div lang="en-US">
<div lang="en-GB">

But not:

<div lang="fr">

This selector is particularly associated with language codes.

8. Case-Insensitive Attribute Matching
CSS can also perform case-insensitive attribute value matching using i.

Example
<input type="TEXT">
<input type="text">
<input type="Text">

Normally:

input[type="text"] {
  color: red;
}

may depend on the attribute's defined matching rules, but for explicit case-insensitive matching you can use:

input[type="text" i] {
  color: red;
}

The i means:

Match regardless of ASCII letter case.

So values such as:

text
TEXT
Text
TeXt

can match.

9. Case-Sensitive Matching With s
CSS also provides the s modifier for explicitly requesting case-sensitive matching where supported.

Example:

[data-theme="dark" s] {
  background: black;
}

This requests case-sensitive comparison.

In practice, you'll encounter i much more often than s.

10. Combining Attribute Selectors
You can combine multiple attribute conditions.

Example
<input type="text" required>
<input type="email" required>
<input type="email">

CSS:

input[type="email"][required] {
  border: 2px solid red;
}

This selects only:

<input type="email" required>

Both conditions must be satisfied.

You can combine attributes with classes too.

<button class="btn" type="submit">Submit</button>
<button class="btn" type="button">Cancel</button>

.btn[type="submit"] {
  background-color: green;
}

Only the submit button gets the green background.

12. Attribute Selector With an Element
You can specify the element before the attribute selector.

input[type="text"] {
  background: yellow;
}

This means:

Select <input> elements whose type attribute equals "text".

Compare that with:

[type="text"] {
  background: yellow;
}

This means:

Select any element whose type attribute equals "text".

The first version is generally more specific about what you intend to target.

13. Attribute Selectors With Multiple Elements
You can use a comma to select multiple things.

input[type="text"],
input[type="email"],
input[type="password"] {
  padding: 10px;
}

All three types receive the same styling.

You could also use:

input[type="text"],
textarea {
  padding: 10px;
}

15. Attribute Selectors vs Classes
Suppose you have:

<button class="submit-button">Submit</button>

You could style it with:

.submit-button {
  background: green;
}

Or, if the HTML tells you enough about the element:

<button type="submit">Submit</button>

you can use:

  background: green;
}

Classes are generally better when you're describing a visual or reusable styling concept:

Attribute selectors are useful when you want styling to depend on an element's semantic/configuration attribute:

input[type="email"]
input[disabled]

Text and Font Properties in CSS
CSS provides many properties for controlling how text looks, aligns, spaces, and behaves.

It's useful to separate them into two groups:

Font properties → control the typeface, size, weight, style, etc.

Text properties → control alignment, spacing, decoration, transformation, wrapping, etc.

1. Font Properties
font-family : 
font-family specifies which font should be used.

p {
  font-family: Arial, sans-serif;
}

You can provide multiple fonts as fallbacks:

p {
  font-family: "Times New Roman", Times, serif;
}

The browser tries the fonts from left to right.

For example:

body {
  font-family: Arial, Helvetica, sans-serif;
}

If Arial isn't available, the browser tries Helvetica, then a generic sans-serif font.

Common generic font families
serif
sans-serif
monospace
cursive
fantasy
system-ui

Example:

.code {
  font-family: monospace;
}

2. font-size
Controls the size of the text.

p {
  font-size: 20px;
}

Common units include:

font-size: 16px;
font-size: 1rem;
font-size: 1.2em;
font-size: 120%;

Example
h1 {
  font-size: 40px;
}

p {
  font-size: 18px;
}


3. font-weight
Controls how thick or bold the text appears.

p {
  font-weight: bold;
}

Common values:

font-weight: normal;
font-weight: bold;

You can also use numeric values:

font-weight: 100;
font-weight: 300;
font-weight: 400;
font-weight: 500;
font-weight: 600;
font-weight: 700;
font-weight: 900;

Generally:

100 → very thin
300 → light
400 → normal
500 → medium
600 → semi-bold
700 → bold
900 → very thick

Example:

h1 {
  font-weight: 700;
}

400 is generally normal weight and 700 is generally bold.


4. font-style
Controls whether text is normal, italic, or oblique.

p {
  font-style: italic;

Common values:

font-style: normal;
font-style: italic;

Example:

5. line-height
line-height controls the vertical space occupied by a line of text.

p {
  line-height: 1.5;
}

You can use:

line-height: 20px;
line-height: 1.5;
line-height: 150%;

For normal body text, unitless values are often convenient:

  font-size: 16px;

This gives a line height of roughly:

Why is line-height important?
Without enough line spacing:

This is a paragraph of text.
This is another line of text.
This can become difficult to read.

With appropriate line spacing:

This is a paragraph of text.

This is another line of text.

This can be easier to read.

it as controlling which element appears in front of or behind another element.

Higher z-index
      ↑
      │

  background: blue;
  z-index: 2;

    │           │
    │           │
    └───────────┘
       Red
  ┌───────────────┐
  │   partially   │

  └───────────────┘
