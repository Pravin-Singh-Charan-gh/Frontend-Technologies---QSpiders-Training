In CSS, the position property controls how an element is placed on a webpage. It is one of the most important concepts for layouts, overlays, menus and fixed headers.

There are 5 main values:

position: static;
position: relative;
position: absolute;
position: fixed;
position: sticky;


1. position: static
static is the default position of every HTML element.

.box {
  position: static;
}

The element stays in the normal document flow.

For example:

<div>Box 1</div>
<div>Box 2</div>
<div>Box 3</div>

They appear normally:

Box 1
Box 2
Box 3

With static, properties like:

top
right
bottom
left

do not work.

Example:

.box {
  position: static;
  top: 50px;
}

top: 50px has no effect.

When to use?

Usually, you don't explicitly write position: static, because it is already the default.



2. position: relative

relative is very important
The element remains in the normal document flow, but you can move it relative to its original position.
But its original space is still reserved.

Example:

.box {
  position: relative;
  top: 20px;
  left: 30px;
}

The element moves:

20px downward
30px to the right

Example

Suppose:

<div class="box1">Box 1</div>
<div class="box2">Box 2</div>

.box1 {
  position: relative;
  left: 50px;
}

Visually:

Original:

Box 1
Box 2


After moving Box 1:

Box 1
Box 2

But the browser still considers Box 1 to occupy its original space.

Why is relative especially important?

Because it is commonly used as a positioning reference for an absolutely positioned child.

Example:

<div class="parent">
  <div class="child">Hello</div>
</div>

.parent {
  position: relative;
}

.child {
  position: absolute;
  top: 0;
  right: 0;
}

Here, .child is positioned relative to .parent.

This is one of the most common CSS patterns.



3. position: absolute

the element is removed from the normal document flow.
That means other elements behave as if the absolutely positioned element isn't occupying its original space.

Example:

.box {
  position: absolute;
  top: 50px;
  left: 100px;
}

The browser positions the element using the nearest appropriate positioned ancestor.
Absolute positioning with a parent

Consider:

<div class="parent">
  <div class="child">
    Child
  </div>
</div>

CSS:

.parent {
  position: relative;
  width: 400px;
  height: 300px;
  background: lightblue;
}

.child {
  position: absolute;
  top: 20px;
  right: 20px;
  background: red;
}

The result is approximately:

+--------------------------------+
|                         Child  |
|                                |
|                                |
|                                |
|                                |
+--------------------------------+

The important relationship is:

.parent
   |
   └── .child

Because .parent has:

position: relative;

the absolute child uses it as its positioning reference.

What if the parent isn't positioned?

Suppose:

.parent {
  width: 400px;
  height: 300px;
}

.child {
  position: absolute;
  top: 20px;
  right: 20px;
}

If there isn't another suitable positioned ancestor, the absolute element is positioned relative to the initial containing block, effectively the page/viewport area.

That's why you often see:

.parent {
  position: relative;
}

.child {
  position: absolute;
}



4. position: fixed
fixed positions an element relative to the viewport.
The viewport is basically the visible area of the browser window.

Example:

.button {
  position: fixed;
  bottom: 20px;
  right: 20px;
}

The button stays in the bottom-right corner.

+--------------------------------------+
|                                      |
|                                      |
|                                      |
|                                      |
|                              [Help]  |
+--------------------------------------+

Even if you scroll:

Scroll ↓

+--------------------------------------+
|                                      |
|        Different content             |
|                                      |
|                              [Help]  |
+--------------------------------------+

The button remains there.

Common uses of fixed
Fixed navbar
.navbar {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
}
Floating button
.chat-button {
  position: fixed;
  bottom: 20px;
  right: 20px;
}
Back-to-top button
.top-button {
  position: fixed;
  bottom: 30px;
  right: 30px;
}



5. position: sticky
sticky is a combination of behavior similar to relative + fixed.

Example:

header {
  position: sticky;
  top: 0;
}

Initially, the element behaves normally.

When you scroll and it reaches:

top: 0;

it sticks to the top of the viewport.

Example

Imagine:

Header
----------------
Content
Content
Content
Content
Content

When scrolling:

Header
----------------
Content
Content
Content

The header remains at the top while its sticky container allows it to remain stuck.

Important: top is usually required

This won't usually produce the sticky behavior you expect:

header {
  position: sticky;
}

You normally need something like:

header {
  position: sticky;
  top: 0;
}

You can also use:

position: sticky;
top: 20px;

or:

position: sticky;
bottom: 0;

depending on the desired behavior.

top: 10px
↓
10px from the top

left: 20px
→
20px from the left

You can also use:

right: 20px;
bottom: 20px;

Example:

.box {
  position: fixed;
  right: 20px;
  bottom: 20px;
}

This puts the box near the bottom-right of the viewport.

Negative values

You can use negative values too.

.box {
  position: relative;
  top: -20px;
}

This moves the element up by 20px.

.box {
  position: relative;
  left: -20px;
}

This moves it left by 20px.
